Stoat is a tiny WordPress theme — around a 103&nbsp;KB zip, almost no
JavaScript, and no Google Fonts.

## Overview

Stoat is a minimal, fast-loading WordPress theme built for blogs and personal
sites. The whole theme zip is about 103&nbsp;KB and ships roughly 15&nbsp;KB of
compressed CSS in a single stylesheet, uses almost no JavaScript, and loads no
Google Fonts — so pages stay light and quick on every device. A clean Stoat site
scores around 99/100 on Lighthouse mobile out of the box, with no caching
plugin, CDN, or tracking code required.

There's no page builder to get between you and your writing. Fonts are
self-hosted through WordPress's Font Library (WordPress 7.0+), with a
system-font fallback on older versions, and the editor is styled to match the
front end so what you write is what you get.

## Features

- Latest version 1.3 (updated July 17, 2026)
- Tiny ~103&nbsp;KB theme zip
- WordPress 7.0 ready, PHP 7 &amp; 8 ready
- Tiny JS, no page builder
- ~15&nbsp;KB of compressed CSS, one stylesheet
- Self-hosted fonts via WordPress's Font Library (WordPress 7.0+)
- Responsive, looks great on all devices
- Text or image logo
- Two menu locations: primary and footer
- Beautiful typography and editor
- Layout: content width, narrow or full for archives, pages, and posts
- Header: light or dark skin, custom colors, and an optional call-to-action button
- Separate nav, heading and body fonts, with heading weight and letter case
- Archive thumbnail ratio and width, plus styled Query Loop blocks
- Wide-image and fullscreen image for writing
- Translation-ready
- Toggle to show or hide most things on the blog and single post

## Changelog {#changelog}

### Version 1.3 — Jul 17, 2026

```
- new: content width and narrow reading column in pixels, plus narrow or full width for archives, pages, and posts (Customize > Layout)
- new: per-page content width override in the page editor's "Page options" box
- new: light or dark header skin, header background and text colors, and header padding (Customize > Header)
- new: header button with primary/black/white/outline styles and an optional new tab; moves into the off-canvas menu on mobile (Customize > Header)
- new: show the featured image above the post content, with its caption (Customize > Single Post)
- new: footer padding (Customize > Footer)
- the footer now follows the content width above it instead of always using the reading column
- styled the Button block in the editor to match the front end, and styled the Details block
```
