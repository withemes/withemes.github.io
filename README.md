# withemes.github.io

The WiThemes site. Plain static HTML, no build step, published with GitHub
Pages from `main` at <https://withemes.github.io/>.

```
index.html          home
about/index.html    about
contact/index.html  contact
style.css           the only stylesheet
```

Edit the HTML, commit, push — live in under a minute.

Preview locally with `python3 -m http.server`.
